# Cardinalidades

Com o modelo conceitual definido, o próximo passo foi calcular e aplicar
as cardinalidades em cada relacionamento, definindo o mínimo e o máximo
de ocorrências entre as entidades envolvidas. Esta etapa é essencial para
identificar os relacionamentos do tipo muitos-para-muitos (N:N), que
precisam ser resolvidos antes de avançar para o modelo lógico.
